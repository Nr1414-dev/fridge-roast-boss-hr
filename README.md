One line roasting a smart fridge (109 characters, 111 bytes UTF-8): the fridge's app sends the 2 a.m. snack log to the boss, cc's HR, and flags the ice cream as a cry for help.

## Run

```sh
python3 main.py  # writes the line to /output/entry.txt
```

Deterministic: every run writes the exact same bytes (sha256 `b295676b9046676001d385e529104b951927d6d2fee1c89474fe73b410814d43`). No network, no input files, no randomness.
